# Telegram Bot 2

Цей бот є клоном оригінального бота, але з наступними змінами:
1. **Адмінка в Телеграмі**: Керування контентом (опис, програма, відгуки, ціна) здійснюється безпосередньо через команду `/admin`.
2. **База даних PostgreSQL**: Дані зберігаються в PostgreSQL, яка запускається через Docker Compose.
3. **Оплата в боті**: Використовується вбудована платіжна система Телеграм (`sendInvoice`).

## Налаштування

1. Відкрийте файл `.env`.
2. Вкажіть ваші дані:
   - `BOT_API_KEY`: Токен вашого бота від @BotFather.
   - `ADMIN_IDS`: Ваші Telegram ID через кому (для доступу до адмінки).
   - `PAYMENT_PROVIDER_TOKEN`: Токен платіжного провайдера.
   - `DATABASE_URL`: URL підключення до БД (за замовчуванням вже налаштовано на Docker).

3. Запустіть базу даних:
   ```bash
   docker-compose up -d
   ```

4. Запустіть бота:
   ```bash
   npm install
   npm run dev
   ```

## Адмін-панель
Надішліть боту команду `/admin`, щоб:
- Змінити опис курсу.
- Змінити програму навчання.
- Оновити відгуки.
- Встановити ціну.
*   **📢 Розсилки**: 
    1. Натисніть "Створити розсилку" і впишіть назву.
    2. У меню розсилки можна додавати ПОВІДОМЛЕННЯ будь-яких типів.
    3. **Нове**: Додано "📝 Перегляд / видалення смс", де можна видалити конкретні повідомлення з ланцюжка розсилки.
    4. Після підготовки натисніть "🚀 ВІДПРАВИТИ ВСІМ".
- Подивитися статистику користувачів та продажів.
